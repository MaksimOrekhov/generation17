# Документы виртуальной студии

Эта папка содержит профессиональные инструкции ролей и шаблоны передачи контекста. Общие правила процесса находятся в [STUDIO_WORKFLOW.md](../STUDIO_WORKFLOW.md), а проверенное состояние кода — в [PROJECT_STATE.md](../PROJECT_STATE.md).

## С чего начать после смены чата

1. Прочитать [общий регламент студии](../STUDIO_WORKFLOW.md).
2. Открыть свою [инструкцию роли](roles/) и проверить её границы полномочий.
3. Сверить [состояние проекта](../PROJECT_STATE.md) с актуальным `main`.
4. Проверить назначенную задачу и её статус в [Linear Generation17](https://linear.app/generation17).
5. Изучить относящийся к задаче код и технические/художественные спецификации в GitHub.
6. Прочитать свой [handoff-шаблон](handoffs/) и заполнить его подтверждёнными актуальными фактами.

## Источники истины

GitHub содержит актуальный код и опубликованные утверждённые документы. Linear хранит задачи, их статусы, исполнителей, блокеры и ссылки на ветки/PR. Чаты помогают вести работу, но не заменяют эти источники.

После merge версии ролевых файлов в GitHub **не синхронизируются автоматически** с копиями инструкций в проекте ChatGPT. Если копии используются в специализированных чатах, продюсер организует их отдельную синхронизацию и сверку.
