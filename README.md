# Поколение 17 / Generation 17

**Играбельный технологический вертикальный срез** минималистичного браузерного симулятора одной жизни на межзвёздном корабле «Пилигрим». Это локальная нарративная симуляция с авторскими историями, а не законченная игра-сервис или симулятор всего корабля.

## Запуск

Требуется Node.js >= 22.12 или >= 20.19 и npm.

```bash
npm install
npm run dev
```

Затем открой адрес, который покажет Vite (обычно http://localhost:5173/).

Проверки:

```bash
npm run build
npm test
npm run sim -- 200
```

Скрипты проверок и симуляций приведены в `package.json`; наличие команды в списке не означает, что она запускалась для текущего коммита.

## Возможности прототипа

- **Атмосфера** на экране рождения: спокойная, с тайнами (рекомендуем) или тревожная. Тайны и жуткие сцены только по выбору игрока, без насилия.
- Экран рождения с жребием: сектор корабля, достаток семьи, здоровье, родители, статистика рождений года и пятеро ровесников. Длина жизни 30 / 60 / 90 минут.
- Время: **1× = 49 секунд на год** (пресеты 22 / 49 / 73 с), скорости 0.5×–16×, пауза, «+1 год», «До решения». Прогресс года показан одной полоской; внутри года приходят фоновые заметки и моменты.
- **Решения** останавливают время и открываются модальным окном; после выбора показывается, что произошло.
- **Моменты** — небольшие возможности внутри года: всплывающая карточка и подсветка места в каюте. Принятие стоит единицу **личного времени**; годовой лимит зависит от режима жизни (3 в детстве, учёбе, на полной ставке, стажировке и переходном периоде; 4 на сокращённой ставке, пенсии и наставничестве). Момент может истечь, если его не принять или не отклонить до следующей отметки года.
- Пиксельная сцена каюты 480×270 на canvas (без файлов-картинок), портреты генерируются из имени.
- Ровесники живут упрощённой жизнью и показываются в финале. Значимые люди имеют устойчивые ID и ограниченное состояние, но их полная автономная повседневная жизнь не симулируется.
- Четыре профессии, блоки сюжетов с отложенными последствиями, карта жизни, летопись, память, смерть и итог.
- Клавиши: `Space` пауза; `→` остаток года; `1`–`4` вариант; `Enter` / `Esc` принять / пропустить момент.
- Подсказки при первой игре и кнопка «Отчёт для тестера»: см. [docs/PLAYTEST.md](docs/PLAYTEST.md).
- Только русский язык; никакого API, сервера и учётных записей. Локальное автосохранение.

## Устройство

См. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Кратко:

```text
src/
  domain/       чистая симуляция без Vue: engine, birth, moments, ambient, clock, mortality, storylets
  stores/       Pinia: состояние (shallowRef), ход времени, сохранение
  render/       пиксельная графика: сцены и спрайты на canvas
  components/   Vue-компоненты: layout, scene, panels, play, birth, common
  composables/  игровой цикл и горячие клавиши
  ui/           форматирование и подписи
  assets/       токены и базовые стили
docs/mockups/   статические макеты интерфейса
```

## Честные ограничения

- В игре **не** симулируются 8 420 индивидуальных жителей: население и рождения представлены агрегатами, а отдельные близкие люди имеют ограниченное состояние и меняются через игровые события.
- Некоторые выборы пока меняют только показатели; зрелые сюжетные цепочки надо усилить.
- Гибкая игровая система и локальный генератор — не LLM. Во время игры не тратятся токены.
- Непротиворечивость сюжетов и баланс не подтверждены человеческими playtest.
- Прототип создан с нуля по концепции. Это не копия проекта 1in8b.life.

## Публикация на GitHub Pages

После успешного workflow `Deploy to GitHub Pages` с принятого `main` актуальная сборка публикуется по адресу [maksimorekhov.github.io/generation17](https://maksimorekhov.github.io/generation17/). Страница публичная; игра хранит сохранение только локально в браузере пользователя, серверного аккаунта и синхронизации нет. Не вводи в игру персональные данные и секреты.

Чтобы проверить опубликованную версию, открой Actions → `Deploy to GitHub Pages` и выбери успешный запуск для нужного commit SHA в `main`; в Pages deployment этого запуска указан опубликованный URL. Сам факт успешной сборки без успешного deployment не подтверждает публикацию. Обычный чат-агент не получает управление открытой страницей от ссылки: браузерный smoke требует доступной среды с Computer Use или браузерной автоматизацией.
