# Generation17 — состояние проекта

Проверенный снимок `main` на 30.10.2026. Изученный commit: [`347e7d3c72251946f9f60a2a37b6db98136d81f7`](https://github.com/MaksimOrekhov/generation17/commit/347e7d3c72251946f9f60a2a37b6db98136d81f7). Состояние описывает файлы и код этой ревизии; наличие документации или экспериментальных скриптов само по себе не подтверждает пользовательское тестирование.

**Обещание игры.** Браузерный нарративный симулятор одной человеческой жизни на корабле поколений «Пилигрим»: игрок взрослеет, работает, строит отношения, выбирает и наблюдает последствия; корабль продолжает путь после смерти героя. Это не AI-chat и не стратегия управления кораблём.

## IMPLEMENTED — подтверждено в коде `main`

- Клиентское приложение на Vue 3, TypeScript, Vite и Pinia. Игровая логика вынесена в чистые функции `src/domain`; canvas используется для сцены. Серверной части и сетевого API в описанном прототипе нет; сохранение локальное.
- Создание жизни с фиксируемым seed, возрастом и атмосферой (`calm`, `mystery`, `uncanny`); ход времени, пауза и ограничение продвижения, годовые события и фоновые отметки.
- Сюжетные решения с несколькими вариантами, проверками навыков, последствиями и записями в истории; отдельные моменты внутри года, которые игрок может принять или пропустить.
- Характеристики героя, корабельные показатели, профессии, фокусы деятельности и кодовые системы работы/экономики, расходов, личного времени и пенсии.
- Устойчивая модель значимых персонажей и отношений, варианты текста с условиями и сохранение состояния жизни. Система не моделирует полную автономную повседневную жизнь всех жителей корабля.
- Автоматические тесты Vitest, проверка контента, TypeScript-проверка, сборка Vite и отдельные воспроизводимые скрипты аудита/симуляции доступны в package scripts. Их наличие здесь не означает, что они были запущены для этой сводки.
