> Снимок на 31.10.2026; код и документы сверены на `main` SHA [`e92b773b178e6042c828d1702ea1e280f075d836`](https://github.com/MaksimOrekhov/generation17/commit/e92b773b178e6042c828d1702ea1e280f075d836). Linear сверена на ту же дату.

- **Роль и границы:** [Инструкция технического архитектора](../roles/ROLE_TECH_ARCHITECT.md). Оценивает архитектурную реализуемость, технические риски и фактический diff; не выбирает продуктовую механику и не разрешает merge.
- **Принятые решения и источники:** [архитектура](../../ARCHITECTURE.md), [состояние проекта](../../PROJECT_STATE.md). Приложение Vue 3/TypeScript/Vite/Pinia; доменная симуляция клиентская и локальная, серверного API нет; сюжетный контент смешанный TypeScript/JSON. Источник конкретной реализации — код на SHA выше. В GEN-15 приняты выводы синтетического natural-delivery QA, но пилот и кодовые изменения не одобрены ([GEN-15](https://linear.app/generation17/issue/GEN-15/novaya-koncepciya-uvlekatelnoj-prichinnoj-biografii-i-igrovogo-cikla)). Архитектурная рекомендация в решении GEN-15 — при необходимости стабильные ID/legacy-index и truth guards; это требования для концепции/проверки, не уже внедрённая система новых ID.
- **Активные задачи Linear и ответственные:** GEN-15 `In Review` — консультировать по stable IDs, truth guards, saves и размеру пилота. GEN-14 `Ready` — запланированная отдельная точечная техническая правка, начать после QA-ТЗ/назначения. GEN-18/19 — консультации в своих областях, пока `Ready`. GEN-16 `Ready` может затронуть контракт placeholders только после аудита. Статусы: [GEN-14](https://linear.app/generation17/issue/GEN-14/tochechnye-ispravleniya-podskazki-skorosti-i-oboznacheniya-vozrasta-v), [GEN-15](https://linear.app/generation17/issue/GEN-15/novaya-koncepciya-uvlekatelnoj-prichinnoj-biografii-i-igrovogo-cikla), [GEN-16](https://linear.app/generation17/issue/GEN-16/polnyj-narrativnyj-audit-sushestvuyushih-tekstov-vozrastov-i-konteksta).
- **Ветки / PR / SHA:** проверенная база `main` — SHA выше. Для текущих консультаций подтверждённой ветки/PR нет. Не путать SHA этой базы с ветками, указанными в полях задач Linear.
- **Незакрытые обязательства:** для GEN-15 оценить stable IDs/legacy mapping, неизвестное/отсутствующее состояние NPC, обратную совместимость сохранений и минимальные изменения только после выбора концепта владельцем. Независимое архитектурное ревью выполнять по реальному diff.
- **Риски и открытые вопросы:** synthetic baseline не доказывает пользовательское поведение. Возможные изменения director, RNG, сохранений, контента или рендера требуют отдельного утверждённого scope. Автотесты не заменяют QA и архитектурное ревью.
